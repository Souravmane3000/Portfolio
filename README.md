# Sourav Mane — Portfolio

Frontend-only portfolio for Sourav Mane, AI Engineer.

## Local development

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm start
```

Personal links and contact details live in `src/config/site.ts`. Project content
and URLs live in `src/config/projects.ts`.

The public resume URL is configured in `src/config/site.ts`.
